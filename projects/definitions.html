Internet

A network which connects different computers.

Web (Not spiderman's webs)

The pages and "websites" which can be accessed by the computers.

How are they different?

Well ... the internet is the connection between computers and the web consists of things which can be accessed by that connection.

ASCII and Unicode

Ways to translate letters and characters into numbers for a computer to understand. ASCII translates from mainly english while unicode allows for a wider variety of symbols.

UTF-8

"Unicode Transformation Format - 8-bit. It represents letters/symbols with bytes.

URL

"Uniform Resource Locator." It tells the computer which page on the web you would like to access.

Domain Name

Like the URL, it shows where something is located. The domain name shows where the website is located, like "google."

HTTP

"HyperText Transfer Protocol." HTTP is used to request a certain webpage, which then returns to the computer by a "HTTP response." Information is sent via HTTP.

HTTPS

The same as HTTP, except the information is encoded for increased security.

IP Address

"Internet Protocol Address." It helps computers recognize each other as computers. It's like a home address ... but for computers.

DNS

"Domain Name System." It takes the Domain name and changes it into an IP address for the computers so that the page can be found.

W3C Recommendations

"World Wide Web Sonsortium." The guidelines for how the internet works-- it tells people how HTMLs should be structured.

XML, XHTML, HTML, HTML5

XML stores data (like making definitions). HTML takes information and creates a web page. XHTML is like HTML, but has "stricter rules." Makes people type out their code with more structure. HTML5 is an updated version of HTML and adds things like video and audio.
