While inline and emedded CSS place the style within the html file, external CSS is located on a separate css file. External CSS files make it easier to manage large projects efficiently and are the CSS standard.

If you use inline or embedded CSS in a large company, there will be confusion between graphical designers and html web developers. External CSS files also make it easier to make large-scale style changes.

The selector comes before the style tag and shows which text will become "selected." (__ {[color]})
